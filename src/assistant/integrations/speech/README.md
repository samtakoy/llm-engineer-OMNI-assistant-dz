# Речевой слой

Запись вопроса с микрофона, распознавание речи и кеш расшифровок.

Пакет не импортирует ничего из проекта, не читает окружение и не пишет в журнал.
Перенос в другой проект - копирование папки вместе с соседним модулем
`../filecache.py` и сборка `SpeechConfig` там, где проекту удобно.

Внешние зависимости: `faster-whisper` для распознавания, `sounddevice` и `numpy`
для записи. Обе группы импортируются внутри функций: без микрофона распознавание
работает, без `faster-whisper` работает запись.

## Использование

```python
from pathlib import Path

from assistant.integrations.speech import SpeechConfig, SpeechRecognizer, record

config = SpeechConfig(
    recognition_model = "medium",
    recognition_device = "auto",
    recognition_compute_type = "int8",
    language = "ru",
    cache_directory = Path(".cache/speech"),
    cache_ttl_days = 0,
    bypass_cache = False,
    recording_sample_rate = 16_000,
    recording_directory = Path("recordings"),
)

recorded = record(seconds = None, config = config)          # None - до нажатия Enter
recognizer = SpeechRecognizer(config = config)
outcome = recognizer.transcribe(audio_path = recorded.path)
print(outcome.text)
```

Распознаватель создаётся один раз и живёт столько, сколько нужно вызывающему:
модель весит от сотен мегабайт до полутора гигабайт и грузится секундами.
Загрузка отложена до первого распознавания.

## SpeechConfig

| Поле | Что задаёт |
| --- | --- |
| `recognition_model` | Модель faster-whisper: `small`, `medium`, `large-v3`. На русском `small` путает имена собственные. |
| `recognition_device` | Устройство вычислений: `auto`, `cpu`, `cuda`. |
| `recognition_compute_type` | Тип вычислений: `int8` на процессоре, `float16` на видеокарте. |
| `language` | Язык записи двумя буквами. Пустая строка - определять по звуку. |
| `cache_directory` | Каталог кеша расшифровок. `None` выключает кеш. |
| `cache_ttl_days` | Сколько дней годна расшифровка. Ноль и меньше - годна всегда. |
| `bypass_cache` | Читать мимо кеша. Запись продолжается. |
| `recording_sample_rate` | Частота дискретизации записи. Whisper всё равно приводит звук к 16 кГц. |
| `recording_directory` | Куда складывать записи с микрофона. |

## Исходы

Ось одна: получилось или нет с краткой причиной. Деления на временный и
постоянный отказ, как в веб-слое, нет - сети нет, и повторять тот же вызов
незачем.

`TranscriptOutcome` несёт текст, причину неудачи и признак попадания в кеш.
`RecordingOutcome` - путь к файлу, причину неудачи, длительность и громкость
самого громкого отсчёта: по ней видно немой микрофон, когда файл записался, а в
нём тишина. Порог тишины - константа `SILENCE_LEVEL`.

## Кеш расшифровок

Ключ - отпечаток содержимого файла вместе с моделью и языком: одну и ту же
запись можно переложить и переименовать, а переслушивать её незачем; смена
модели даёт другую запись, и старая расшифровка не выдаётся за новую. Записи
складываются в подкаталог `transcripts`.

## Микрофон в macOS

Разрешение на микрофон спрашивается у процесса-родителя - терминала или ide, а
не у python, и диалог всплывает не всегда. Без разрешения запись идёт молча и
даёт тишину, поэтому в `RecordingOutcome` есть `peak_level`: ниже `SILENCE_LEVEL`
- микрофон не слышно, и об этом надо сказать пользователю вслух.

Выдаётся руками: Системные настройки → Конфиденциальность и безопасность →
Микрофон, включить приложение, из которого идёт запуск. Если его нет в списке,
диалог был отклонён раньше и запрос возвращается сбросом:

```
tccutil reset Microphone com.apple.Terminal
```

После сброса приложение нужно перезапустить. Список видимых устройств ввода:

```
python -c "import sounddevice; print(sounddevice.query_devices())"
```
